SESSION A — Power & Climbing (45 min)  [Tue]
  Bulgarian split squats         4 x 8 each leg (heavy — add weight each week)
  Step-ups with knee drive        3 x 12 each leg (use box/step 40–50cm)
  Single-leg Romanian deadlift    3 x 10 each leg
  Box jumps                       3 x 8 (explosive)
  Calf raises on incline          3 x 20 each leg (slow eccentric)
  Dead bugs                       3 x 10 (core)

SESSION B — Stability & Injury Prevention (35 min)  [Sun]
  Single-leg glute bridge         3 x 15 each
  Lateral band walks              3 x 20 each direction
  Copenhagen plank                3 x 30 sec each side
  Nordic hamstring curls          3 x 6 (slow eccentric — key injury preventer)
  Single-leg balance on wobble    3 x 60 sec each (eyes closed progression)
  Side plank hip abduction        3 x 12 each

TAPER ADJUSTMENTS FOR STRENGTH:
  Week 6: Last heavy Session A — reduce weight by 10%
  Week 7: Session B only — drop sets to 2x, reduce load 20%
  Week 8+: No strength — just mobility/stretching
